Critic guard live test, 2026-10-15 (M1 step 0)

The player-critic agent is not listed in the session that installed it (agents load at session
start), so the live test ran through a separate headless Claude Code process from the repo root:
  claude -p "<invoke player-critic with the prompt below>" --model sonnet --allowedTools Agent

So $CLAUDE_PROJECT_DIR expands, the hook runs, and exit 2 blocks. The SubagentHandback call the
critic uses to report back is allowed by the guard, as intended.
tools/test_guard.py (installed guard): guard: ok.

Consequence for the workflow: in any session, the critic can be run through a headless process
(tools/critic.py), so a review does not have to wait for a new session to list the agent.
