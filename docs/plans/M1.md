# M1 checklist: find the fun

Goal from the kickoff: a vertical slice. One starting drill ship with about six rooms, three crew,
power allocation, the heat system plus fire and at least one kind of breach, one layer with a node
map of about eight stops, the drilling segment between nodes, one combat enemy, one store, a few
events, and a full run from start to death to codex. Stewart playtests it; iterate on the core loop
before building out content.

Split: **M1a** is autonomous and ends with an exported playtest build and a STOP for Stewart.
**M1b** iterates on his notes until he says the loop is fun.
